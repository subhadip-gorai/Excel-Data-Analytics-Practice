# Excel Data Analytics Practice

A structured collection of hands-on Excel practice exercises focused on
developing practical skills for Data Analytics.

This repository documents my learning journey with Microsoft Excel,
covering formulas, data cleaning, lookups, PivotTables, data analysis,
and data visualization.

---

## 📚 Topics Covered

### Formulas & Functions
- IF Function
- AND Function
- OR Function
- Logical Functions
- Lookup Functions
- Statistical Functions
- Formula-based Data Analysis

### Data Cleaning
- Identifying and handling data issues
- Removing unnecessary data
- Formatting and organizing datasets
- Preparing data for analysis

### PivotTables
- Creating PivotTables
- Summarizing data
- Grouping and analyzing data
- PivotTable-based analysis

### Data Visualization
- Charts
- Histogram
- Data visualization
- Chart formatting
- Presenting analytical insights

### Statistical Data Analysis
- Univariate Analysis
- Bivariate Analysis
- Box Plot
- Scatter Plot
